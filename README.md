# IPL Data Analysis

## Project Overview
This project focuses on analyzing IPL cricket data using Python. It involves cleaning raw datasets, calculating player and team performance statistics, and creating visualizations to identify top performers.

## Objectives
- Clean and transform raw IPL datasets using Pandas.
- Analyze batting and bowling performances.
- Compare team performances.
- Visualize top-performing players using Matplotlib and Seaborn.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Files
- `IPL_Data_Analysis.ipynb` – Complete data cleaning, analysis, and visualization notebook.

## Key Analysis
- Top 10 run scorers
- Top 10 wicket takers
- Batting strike rates
- Bowling economy
- Team wins and win percentages
- Player performance visualizations

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required IPL CSV datasets.
3. Run all notebook cells in sequence.
